# 01: Защищённое удаление прогулки через overflow-меню на WalkCard и модальное окно подтверждения

**What to build:** Убрать прямое удаление прогулки в один клик на карточках прошлых прогулок (`WalkCard`) главного экрана (`HomeScreen`): перенести второстепенные действия (`Export GPX` и `Delete`) в overflow-меню `⋮` в правом верхнем углу карточки (с переносом даты под название маршрута и сохранением только 2 основных кнопок в нижнем ряду) и добавить OLED-диалог подтверждения (`DeleteWalkConfirmationDialog`), чтобы удаление прогулки из базы данных Room и с главного экрана происходило исключительно после явного подтверждения пользователем. Spec: `docs/specs/safe-walk-deletion.md`.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] На `WalkCard` в шапке карточки дата прогулки отображается второй строкой под названием маршрута, а в правом верхнем углу размещена кнопка overflow-меню (`⋮`, `contentDescription = "More options"`).
- [x] В выпадающем меню `⋮` отображаются два пункта: `"Export GPX"` (с иконкой `Share`, `TextPrimary`) и ниже через разделитель `"Delete"` (с иконкой `DeleteOutline`, `ErrorRed`).
- [x] В нижнем ряду действий `WalkCard` остаются только две основные кнопки: `"Walk with Ghost"` и `"View track on map"` (прямые кнопки `Export GPX` и `Delete walk` удалены).
- [x] Выбор `"Export GPX"` в меню закрывает меню и запускает экспорт GPX без показа диалога удаления.
- [x] Выбор `"Delete"` в меню закрывает меню и открывает Material3 OLED-диалог `"Delete walk?"` с названием прогулки, её датой, дистанцией и предупреждением `"This action cannot be undone."`, а также кнопками `"Cancel"` и красной `"Delete"` (`ErrorRed`).
- [x] Нажатие `"Cancel"`, тап вне диалога или кнопка «Назад» закрывают диалог без удаления прогулки из БД и списка; нажатие `"Delete"` в диалоге закрывает диалог, удаляет прогулку из Room DB (со сбросом кэша тепловой карты) и показывает снэкбар `"Walk deleted"`.
- [x] Все пользовательские строки и `contentDescription` строго на английском языке.
- [x] Добавлен Robolectric + Compose UI тест (`WalkCardDeleteFlowTest`), проверяющий весь сценарий: отсутствие прямых кнопок, открытие меню, экспорт GPX, открытие диалога без преждевременного удаления, отмену (`Cancel` и dismiss) и подтверждение удаления.
- [x] Проходят `.\gradlew.bat testDebugUnitTest`, `pwsh scripts/check_localization.ps1` и `pwsh scripts/check_android_compat.ps1`.
