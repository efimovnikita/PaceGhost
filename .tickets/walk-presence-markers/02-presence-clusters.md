# 02: Presence Clusters по экранной сетке с бейджем числа

**What to build:** Близкие прогулки объединяются в Presence Cluster по экранной сетке 64dp. На каждом кластере всегда отображается число прогулок (включая «1», «99+» для больших), радиус растёт логарифмически 8–14dp. При приближении кластеры распадаются; пересчёт происходит по завершении зума/скролла с debounce, а не на каждый кадр.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Чистый доменный кластеризатор (pure JVM тесты): две близкие прогулки на низком zoom → 1 кластер count=2, на более высоком → 2 кластера; далёкие города → разные кластеры; zoom ≥ 10 или пустой вход → пустой результат.
- [ ] Функция радиуса: count=1 → 8dp, монотонный рост, кламп 14dp (тест).
- [ ] Порог cutoff берётся из единого источника с heatmap tile provider.
- [ ] Маркеры показывают число; кластеры пересчитываются после окончания зума/скролла.
- [ ] `.\gradlew.bat testDebugUnitTest` зелёный.
