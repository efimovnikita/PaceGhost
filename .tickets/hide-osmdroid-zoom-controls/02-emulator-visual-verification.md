# 02: Визуальная верификация Personal Heatmap на Android-эмуляторе

**What to build:** Собрать debug APK, установить и открыть экран **Personal Heatmap** на Android-эмуляторе, выполнить взаимодействие с картой (пан/зум) и подтвердить скриншотом в артефакте, что дублирующиеся белые кнопки `-` / `+` по центру снизу больше не появляются, а кастомные OLED-кнопки `+` / `-` и `Recenter` справа внизу работают штатно. Spec: `docs/specs/hide-osmdroid-zoom-controls.md`.

**Blocked by:** 01: Скрытие встроенных кнопок зума osmdroid на всех картах через общую конфигурацию

**Status:** done

- [x] Успешно собран debug APK (`.\gradlew.bat assembleDebug`).
- [x] Приложение установлено и запущено на Android-эмуляторе, открыт экран **Personal Heatmap**.
- [x] На экране **Personal Heatmap** выполнен свайп (панорамирование) карты и/или зум, и скриншот снят **немедленно** после жеста (в пределах ~0.3–0.5 сек, до возможного fade-out стандартного `SHOW_AND_FADEOUT`), подтверждая, что белые системные кнопки `-` / `+` внизу по центру не появляются вовсе.
